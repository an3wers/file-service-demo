Refresh-токенHttpOnly cookie; в БД — хешПостоянный случайный секрет. Cookie получает 7 дней при входе и каждом refresh.
Сессияauth_sessions7 дней с создания или последнего продления. Общего календарного предела нет.

Cookie: HttpOnly, SameSite=Strict, Path=/api/auth, без Domain. Secure зависит от окружения; рабочее окружение использует HTTPS.

Граница схемы: регистрация и активация сами сессию не создают. Здесь подробно показан вход активного пользователя; восстановление пароля отражено как причина отзыва сессий. Лимиты запросов и внутренние транзакции укрупнены.

Принятый риск: ротации refresh-токена нет. Похищенный секрет можно использовать для продления до отзыва сессии. Уже выданные JWT и подписанные ссылки не отзываются вместе с ней.
